# VES Field Assistant™

Offline-first field app for **Vertical Electrical Sounding (VES)** — by **Dr. Uche Aluge Daniel** (*The Borehole Doctor* 🩺).

Log soundings straight from your phone, get instant geometric-factor (K) and apparent-resistivity (ρₐ) computation, watch the log–log curve draw live, flag bad readings before you leave site, and let the on-device AI interpreter read the curve type (H, K, A, Q) with plain-English layer guidance.

- Works fully offline — no internet needed in the field
- Schlumberger, Wenner & Half-Schlumberger arrays
- Station map, voice notes, site photos, CSV + Word-ready report export

🌍 Live app: https://dealphaseriezltd-ctrl.github.io/ves-field-assistant/
